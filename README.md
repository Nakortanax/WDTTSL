## Что такое VPNSL

VPNSL — это клиент-серверный VPN для собственного Linux-сервера. Проект объединяет:

- **Windows-клиент** с графическим интерфейсом, Wintun и full-tunnel IPv4;
- **Android-клиент** с маршрутизацией по приложениям;
- **Rust-клиент и Linux-сервер** CSQTT/VPNSL;
- установку сервера по SSH прямо из Windows-интерфейса;
- управляемую маршрутизацию для сайтов, подсетей и отдельных IPv4-адресов.

Главная идея Windows-версии проста: **весь IPv4-трафик идёт через VPN, кроме тех ресурсов, которые пользователь явно отправил «Напрямую» через обычное подключение Windows**.

## Windows 1.0.1 — как работает маршрутизация

После подключения VPNSL устанавливает full-tunnel для IPv4. Основной трафик проходит через виртуальный Wintun-интерфейс, а транспорт самого VPN и TURN-соединения защищаются отдельными прямыми маршрутами через физическое подключение, чтобы туннель не попытался маршрутизировать сам себя.

Для full-tunnel используются два более специфичных маршрута:

```text
0.0.0.0/1       → VPNSL / Wintun
128.0.0.0/1     → VPNSL / Wintun
```

Обычный системный `0.0.0.0/0` остаётся в Windows. Поэтому более специфичные правила из профилей **«Напрямую»** имеют приоритет и могут обходить VPN.

```text
Обычный IPv4-трафик ───────────────→ VPNSL → Интернет
                                        ▲
                                        │ full-tunnel

Профили «Напрямую» ────────────────→ физический шлюз → Интернет
Peer / TURN транспорта ────────────→ физический шлюз
```

### Что умеет вкладка «Маршруты»

- **Напрямую** — отправить выбранный IPv4/CIDR в обход VPNSL;
- **Через VPNSL** — явно закрепить сеть или адрес за туннелем;
- включать и выключать профили без удаления их из списка;
- импортировать `.bat`, `.txt` и `.list`;
- применять большие наборы IPv4-маршрутов;
- создавать профиль по имени сайта;
- экспортировать набор маршрутов в BAT.

### Что исправлено в 1.0.1

Версия 1.0.1 исправляет работу исключений **«Напрямую»** при активном full-tunnel. Теперь клиент:

1. сначала стабилизирует основной VPN-маршрут;
2. после этого устанавливает пользовательские исключения через физический шлюз;
3. повторно проверяет их отдельным процессом Windows;
4. при необходимости восстанавливает потерянные маршруты;
5. для профилей с именем сайта дополнительно обновляет текущие IPv4 DNS-адреса домена.

Это позволяет, например, оставить основной интернет внутри VPN, а сервис вроде **Ozon** направить напрямую: профиль можно включать и выключать во время работы, и направление трафика изменяется вместе с ним.

> [!NOTE]
> Full-tunnel Windows и пользовательские правила текущей версии относятся к **IPv4**. IPv6 пока не объявляется как туннелируемый.

## Быстрый старт — Windows

1. Скачайте **[VPNSL Windows 1.0.1](https://github.com/Nakortanax/WDTTSL/releases/tag/windows-v1.0.1)**.
2. Для обычной установки запустите `VPNSL-1.0.1-Windows-x64-Setup.exe`.
3. Для portable-версии полностью распакуйте ZIP и запустите `VPNSL.Windows.exe`.
4. Подтвердите UAC — права администратора требуются для Wintun и маршрутов Windows.
5. Укажите параметры Peer/сервера и подключитесь.
6. После поднятия туннеля весь IPv4-трафик по умолчанию будет идти через VPNSL.
7. Ресурсы, которым VPN мешает, добавляйте во вкладке **«Маршруты»** с направлением **«Напрямую»**.

### Пример профиля сайта

Можно импортировать готовый BAT со списком сетей и выбрать направление **«Напрямую»**. Если файл называется, например, `ozon.ru.bat`, VPNSL 1.0.1 дополнительно пытается определить актуальные IPv4-адреса `ozon.ru`/`www.ozon.ru` и закрепить их за прямым подключением.

Это полезно для сайтов и CDN, у которых адреса со временем меняются.

## Android

Android-версия использует `VPNService` и поддерживает маршрутизацию по приложениям. Пользователь может выбрать один из двух сценариев:

- направлять в VPN только выбранные приложения;
- исключать выбранные приложения из VPN.

Такой подход удобен для мобильных приложений, использующих большое количество неизвестных заранее серверов/CDN: вместо ручного списка адресов выбирается само приложение.

Дополнительно доступны Android TV-интерфейс, Quick Settings Tile, виджет и сетевые политики Android.

## Установка собственного сервера

Windows-клиент содержит вкладку установки сервера. Через SSH можно подготовить совместимый Linux-хост и загрузить серверный бинарник для нужной архитектуры:

```text
amd64
arm64
armv7
```

Проект не предоставляет коммерческий VPN-сервис — сервер разворачивается пользователем самостоятельно.

## Ограничения Windows

- Windows 10/11 **x64**;
- маршрутизация текущей версии — **IPv4**;
- выбор приложений реализован только на Android;
- для Wintun и изменения системных маршрутов нужны права администратора;
- сайты/CDN могут менять IP, поэтому для сложных сервисов лучше использовать актуальные списки сетей и доменные профили;
- приложение не изменяет ваш обычный default route навсегда — созданные VPNSL маршруты очищаются при штатном отключении.

# VPNSL Windows 1.0.1

VPNSL для Windows 10/11 x64 — графический VPN-клиент на базе CSQTT/VPNSL с Wintun, full-tunnel IPv4 и управляемыми исключениями маршрутизации.

## Основной режим работы

После подключения весь IPv4-трафик Windows по умолчанию направляется через VPNSL.

Для full-tunnel используются более специфичные маршруты:

```text
0.0.0.0/1       -> VPNSL / Wintun
128.0.0.0/1     -> VPNSL / Wintun
```

Системный default route Windows остаётся на месте. Это позволяет более специфичным правилам профилей «Напрямую» выводить отдельные адреса и сети из VPN.

## Маршрутизация

Во вкладке «Маршруты» поддерживаются:

- направление «Напрямую» — через обычный физический шлюз Windows;
- направление «Через VPNSL» — через туннель;
- включение и отключение профилей;
- IPv4 и CIDR;
- импорт `.bat`, `.txt` и `.list`;
- большие наборы маршрутов;
- создание профиля по доменному имени;
- экспорт маршрутов в BAT.

### Изменения 1.0.1

В 1.0.1 исправлена работа профилей «Напрямую» при активном full-tunnel.

Теперь программа:

1. сначала стабилизирует основной VPN-маршрут;
2. затем устанавливает пользовательские прямые исключения через физический шлюз;
3. повторно проверяет их отдельным процессом Windows;
4. при необходимости восстанавливает маршруты;
5. для профилей с именем сайта дополнительно обновляет актуальные IPv4 DNS-адреса домена.

Например, можно импортировать `ozon.ru.bat`, назначить профиль «Напрямую» и включать/выключать его во время работы VPN.

## Защита транспорта VPNSL

Peer VPNSL и обнаруженные TURN-адреса получают отдельные прямые маршруты через физическое подключение. Это предотвращает ситуацию, когда full-tunnel пытается отправить транспорт VPN обратно внутрь собственного туннеля.

## Архитектура

```text
Windows applications
        |
        v
Windows routing table
        |
        v
Wintun
        |
        v
VPNSL.Windows.exe <-> local UDP <-> client.exe
                                     |
                                     v
                              VPNSL / CSQTT server
                                     |
                                     v
                                  Internet
```

Windows UI запускает существующий Rust `client.exe` в packet mode, создаёт Wintun, получает параметры TUN и управляет таблицей маршрутизации Windows.

## Что сохранено от CSQTT / Android

- Rust transport и wire protocol;
- Peer/password/VK hash;
- количество воркеров;
- маскировка и TURN transport;
- captcha/auth параметры;
- логи подключения и статистика трафика;
- совместимость с сервером VPNSL/CSQTT.

## Отличие от Android

Выбор установленных приложений в Windows-версии намеренно не реализован. В Windows маршрутизация выполняется по IPv4/CIDR, доменным профилям и импортированным файлам.

Windows-клиент не отключает VPN при Wi-Fi. Физическое подключение может быть Ethernet, Wi-Fi или другим интерфейсом Windows.

## Portable

Распакуйте ZIP полностью. Не переносите `VPNSL.Windows.exe` отдельно.

В папке должны находиться как минимум:

- `VPNSL.Windows.exe`
- `client.exe`
- `wintun.dll`
- `server-assets`

Запускайте `VPNSL.Windows.exe`. Программа сама запросит UAC, потому что Wintun, IP/DNS и системные маршруты требуют прав администратора.

Диагностический лог запуска:

```text
%APPDATA%\VPNSL\startup.log
```

## Установщик

`VPNSL-1.0.1-Windows-x64-Setup.exe` устанавливает приложение в Program Files и создаёт стандартные ярлыки. После запуска само приложение запрашивает необходимые права администратора.

## Ограничения

- Windows 10/11 x64;
- текущая маршрутизация — IPv4;
- выбор приложений есть только в Android-клиенте;
- для изменения маршрутов нужны права администратора;
- IP сайтов/CDN могут изменяться, поэтому сложные профили периодически требуют актуализации.

## Сервер

Windows-сборка содержит `server-assets` для Linux:

```text
amd64
arm64
armv7
```

Сервер можно разворачивать самостоятельно, в том числе через SSH-функции Windows-клиента.

## Происхождение

VPNSL/WDTTSL основан на проекте `amurcanov/csqtt`.

Оригинальный протокол, Android-клиент и Rust-ядро происходят из upstream. Windows-адаптация, Wintun-интеграция, интерфейс и дополнительная логика маршрутизации развиваются в репозитории Nakortanax/WDTTSL.

# VPNSL Windows 1.0.3 — server deploy hardening

Цель версии: устранить повторение ошибки установки Linux-сервера из Windows-клиента, при которой `deploy.sh` попадал на Linux с CRLF и Bash завершался ошибками `$'\\r': command not found` / `set: pipefail`.

## Исправления

- `deploy.sh` читается как текст и перед SFTP всегда нормализуется:
  - UTF-8 BOM удаляется;
  - CRLF -> LF;
  - CR -> LF.
- Нормализованный скрипт отправляется UTF-8 без BOM.
- После загрузки выполняется удалённая проверка:
  `sed -i 's/\\r$//' /tmp/deploy.sh && bash -n /tmp/deploy.sh`.
- Проверка выполняется до загрузки/установки нового server binary.
- Такой же механизм используется при штатном удалении сервера.
- После каждой SFTP-загрузки проверяется размер удалённого файла.
- Пустые server-assets отклоняются до начала установки.
- При сборке Windows-пакета `server-assets/deploy.sh` дополнительно нормализуется и проверяется на отсутствие CR и UTF-8 BOM.
- Проверяется наличие всех server binaries: amd64, arm64, armv7.

## Совместимость

Маршрутизация и интерфейс Windows 1.0.2 сохраняются. Серверный wire protocol не меняется.

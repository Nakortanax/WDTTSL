# CSQTT: экспорт профилей КВН и оценка обновления на v2.5.0

Дата: 21 ноября 2026. Доработка действующего сервера на основе CSQTT 2.1.9.

## Выдача файлов КВН

В карточке существующего клиента добавлена кнопка **«⬇ Скачать КВН»**. Она формирует JSON `.kvn` формата `kvn-csqtt` версии 1, который импортируют Windows и Android КВН. Файл содержит `name`, `endpoint`, `vk_hashes` и `password`.

При выдаче не вызываются API создания/изменения/удаления клиентов, не перезаписываются пользовательские записи и не изменяются привязки устройств. Адрес `host:port` запрашивается при скачивании; нужно указывать адрес, достижимый на устройстве клиента, а не обязательно внутренний IP сервера. Для старых клиентов без записанных VK-хешей панель запрашивает реальные действующие хеши при экспорте. Если они неизвестны, готовый рабочий профиль автоматически выдать нельзя. Кнопка недоступна для главного административного пароля.

**Безопасность:** файл `.kvn` содержит пароль и VK-хеши открытым текстом. Скачивать и передавать его только доверенному владельцу устройства по защищённому каналу; не загружать в публичные репозитории и журналы. Новых эндпоинтов с выдачей секретов не добавлено — формирование происходит в уже авторизованном интерфейсе.

## Что проверено

- Компиляция `rust-server` версии 2.1.9 с новой кнопкой, `cargo build --locked --release` в отдельном Docker-окружении Rust 1.97.1.
- JavaScript страницы — `node --check`; пример профиля успешно проходит проверку формы `kvn-csqtt` v1.
- Авторизованная HTTPS-панель отвечает HTTP 200 и содержит новую кнопку; API существующих клиентов работает.
- После краткого перезапуска сервер слушает прежние TCP/UDP-порты и обслуживает пользователей.
- Снимок SQLite, снятый через SQLite Backup API с учётом WAL, проходит `integrity_check`.
- Идентификаторы пользователей, привязки устройств и критичные параметры БД сверены до и после установки и не изменились. Старый бинарник, служба, конфигурация и сертификаты сохранены в закрытой резервной копии вне Git.

## Анализ официального CSQTT v2.5.0

Официальный тег: https://github.com/amurcanov/csqtt/releases/tag/v2.5.0; код: https://github.com/amurcanov/csqtt/tree/v2.5.0/rust-server. В `Cargo.toml` версия сервера — 2.5.0. Релиз добавляет новые серверные функции и меняет модель клиентов, групп, маршрутизации и транспортов. В описании релиза автор предупреждает, что новые серверные функции не гарантированно работают; репозиторий архивирован.

В действующей базе 2.1.9 таблица `passwords` содержит `device_id`, а отдельная таблица `devices` хранит прежние привязки. Код 2.5.0 использует новую схему `passwords.ip`, групп и маршрутов; старую `devices` не читает тем же способом. Миграция добавляет столбцы, но сама по себе не подтверждает сохранение прежних привязок и авторизации устройств. **Поэтому бинарник v2.5.0 не был установлен поверх работающего сервера.**

Перед обновлением требуется на изолированной копии: загрузить сохранённую БД и ключевые настройки, подтвердить миграцию всех пользователей и устройств без создания новых учётных записей, проверить аутентификацию старых клиентов и реальную передачу трафика, сравнить настройки и открыть рабочую панель. Только после этого — короткое переключение с автоматическим откатом. Стабильный сервер пока остаётся на протоколе/ядре **2.1.9** с интерфейсной доработкой КВН.

Также следует отдельно проверить противоречие лицензий: в `Cargo.toml` тега 2.5.0 указано `Unlicense`, но README исходного проекта содержит прямое некоммерческое ограничение и ссылается на PolyForm Noncommercial; это не основание считать коммерческое использование свободным.
